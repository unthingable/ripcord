Takeaway

Both cyan and teal wash out a bit as text on light backgrounds. SwiftUI's built-in .cyan and .teal already handle this — they ship with adaptive dark/light variants that darken automatically.

If using SwiftUI system colors (Color.blue, Color.cyan, Color.teal), this is free. Only matters if defining custom hex values.

Rev 2 (teal) has slightly better light-mode legibility out of the box since it's already darker. Rev 1 (cyan) has more hue separation from blue but needs the adaptive shade in light mode.
